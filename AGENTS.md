# Studio 1Way

Spring Boot + React/TypeScript site for the Studio 1Way art studio.
Deployed from `main` via CircleCI to Heroku. Dev commands live in
`bin/` (run `bin/list`); `bin/native/` runs the same flows without
Docker.

## Skills

- Adding a portfolio project: `.agents/skills/add-project/SKILL.md`
  (project JSON format, image sets, field rules, validation scripts).
  A pointer copy lives under `.claude/skills/add-project/` for tools
  that only scan that directory.
